# 📖 Llegaste Tarde a la IA

**La Guía para Ponerte al Corriente y Hacerte Exitoso en Tu Carrera**

> Para profesionales no técnicos que quieren usar IA en su trabajo sin aprender a programar.

## 🎯 ¿Para quién es este libro?

Profesionales de **marketing, ventas, RRHH, finanzas, legal, administración, contaduría y emprendimiento** en México y LATAM (28-50 años) que:

- Se sienten abrumados porque "llegaron tarde" a la IA
- Todavía pelean con Excel
- Quieren usar IA para ser más productivos
- No quieren (ni necesitan) aprender a programar

## 🌐 Sitio Web Companion

El sitio web contiene los 40 prompts del libro listos para copiar y pegar, el glosario de 30 términos de IA y la tabla de contenidos interactiva. Optimizado para SEO con HTML semántico, structured data (JSON-LD), Open Graph y meta tags.

**Sitio en vivo:** https://llegaste-tarde-ia.mx

**Archivo principal:** `index.html` (HTML estático, SEO-friendly)
